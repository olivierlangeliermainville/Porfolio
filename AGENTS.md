## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project

See README.md for the structure and conventions. Content lives in `src/data/` (no CMS): edit those files rather than hardcoding text in components.
